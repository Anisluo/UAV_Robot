## 一、学习目标回顾

我们的目标是做：

- 六轴机械臂 3D 视觉抓取

在前面的课程中已经分析过，实现 3D 视觉抓取的核心在于：

- 准确获取目标物体的三维坐标
- 将该三维坐标映射到机械臂基坐标系
- 再由机械臂运动到对应目标点

本课程使用的方法是：

### 1. 获取物体三维坐标

- 使用目标检测算法获取 RGB 图像中的物体几何中心
- 使用深度相机 `D435` 获取对应三维坐标

### 2. 将物体坐标转为机械臂基坐标系

- 使用 `Aruco` 做眼在手外标定

### 3. 驱动机械臂运动

- 直接调用 `Move XYZ`
- 或用逆运动学求关节角，再调用 `MoveJ`

本节重点处理的是前两个问题：

1. 如何获取目标物体在相机坐标系下的三维坐标？
2. 这个三维坐标如何转换到机械臂基坐标系？

它们本质上都属于：

- `坐标系之间的转换问题`

## 二、常见的坐标系、定义与关系

机械臂视觉抓取中，通常会涉及以下几类坐标系：

| 记号 | 中文名称 | 常见符号 | 原点与轴的物理含义 |
|---|---|---|---|
| 图像坐标系 / 像素平面 | 像素坐标系 | `(u, v)` | 原点通常在左上角或主点，`u` 向右，`v` 向下 |
| 相机坐标系 | Camera Frame | `C` | 原点在相机光心，`Z` 轴沿光轴方向 |
| 标定板坐标系 | Board / Target Frame | `B` / `T` | 原点通常在棋盘格或 Aruco 标记定义处 |
| 工具坐标系 | Tool Frame / TCP | `E` / `TCP` | 原点在工具中心点，轴方向由机器人定义 |
| 机器人基座坐标系 | Base / World Frame | `Base` / `W` | 原点在机械臂底座，`Z` 轴通常竖直向上 |

不同资料的记号可能不同，但本质都类似。

### 本课程要做的两个转换

#### 问题 1：如何获取目标物体在相机坐标系下的三维坐标？

本质是：

- 从像素坐标系 `(u, v)` 转到相机坐标系 `(X, Y, Z)`

#### 问题 2：如何把相机坐标系下的三维坐标转换到机械臂基坐标系？

本质是：

- 从相机坐标系 `C` 转到机器人基坐标系 `Base`

## 三、如何获取目标物体在相机坐标系下的三维坐标？

通常流程如下：

1. 用目标检测算法获取 RGB 图像中的目标中心像素坐标
2. 从深度图中读取该像素的深度值
3. 获取相机内参
4. 使用反投影将像素坐标恢复为相机坐标系下的三维点

---

## 3.1 相机内参——从像素坐标到相机坐标

---

## 3.1.1 针孔相机模型

针孔相机模型是相机成像最经典的简化模型。

可以把相机想成一个暗盒：

- 前面有一个小孔
- 后面有成像平面

来自物体各点的光线穿过针孔后，会在成像平面上形成图像。

它有几个重要特点：

- 远处的物体成像更小
- 图像是倒立的
- 针孔与成像平面的距离影响视场和放大倍率

虽然真实相机比针孔模型更复杂，但对几何建模来说，这个模型已经足够实用。

---

## 3.1.2 相机参数

针孔相机模型中有几个核心参数：

- 投影中心（针孔）
- 焦距
- 光轴
- 主点

它们共同决定了三维点如何投影到图像平面上。

---

## 3.1.3 焦距

空间中一点 `(X, Y, Z)` 投影到图像平面 `(u, v)` 时，焦距决定了成像比例。

注意：

- 物理焦距通常以毫米为单位
- 相机标定中更常用的是像素单位下的焦距 `fx`、`fy`

之所以有两个焦距，是因为：

- 传感器像素可能不是完全正方形
- `x` 方向和 `y` 方向的缩放比例可能不同

---

## 3.1.4 相机内参矩阵（Camera Intrinsic Matrix）

将投影关系写成矩阵形式后，可以得到相机内参矩阵 `K`。

通常内参矩阵包含：

- `fx`
- `fy`
- `cx`
- `cy`

其中：

- `fx, fy` 是像素单位下的焦距
- `cx, cy` 是主点坐标

相机内参矩阵是相机成像的固定参数，在相机出厂后通常不会变化。

内参矩阵的目标是完成：

- 相机坐标 -> 像素坐标

而反投影则是它的逆过程。

---

## 3.1.5 反投影

在深度相机应用中，我们最关心的是：

- 已知像素坐标 `(u, v)`
- 已知深度 `Z`
- 如何恢复相机坐标系下的三维点 `(X, Y, Z)`

这就是：

- `反投影（de-projection）`

### 常见分量形式

当已知相机内参时，可按如下方式计算：

```python
X = (u - cx) * Z / fx
Y = (v - cy) * Z / fy
Z = depth
```

这意味着：

- 只要知道像素坐标和深度值
- 就能恢复三维点

### RealSense API 示例

对于 D435，可以直接调用官方 API：

```python
z = depth_frame.get_distance(x, y)
x_cam, y_cam, z_cam = rs.rs2_deproject_pixel_to_point(intr, [x, y], z)
```

也可以手动反投影：

```python
X_m = (x - intr.ppx) * z / intr.fx
Y_m = (y - intr.ppy) * z / intr.fy
Z_m = z
```

### 实践建议

实际项目中，建议优先使用：

- 相机厂家官方 API

因为厂家已经处理了：

- 图像校正
- 深度对齐
- 内参匹配

## 3.1.6 相机内参标定

如果需要自己求相机内参，就要做：

- `相机标定`

最常见的方法是：

- 棋盘格 + OpenCV

### 标定目标

标定通常用于求出：

- 焦距 `fx, fy`
- 主点 `cx, cy`
- 畸变系数

### 常见流程

1. 准备棋盘格
2. 拍摄多张不同角度、不同距离的图片
3. 检测角点
4. 使用 OpenCV 求解内参与畸变

### 推荐拍摄要求

- 至少 20 张以上
- 覆盖不同距离、不同角度
- 光照均匀
- 避免反光
- 保持原始分辨率
- 关闭自动对焦

### OpenCV 标定步骤

典型 API 包括：

- `cv2.findChessboardCorners`
- `cv2.cornerSubPix`
- `cv2.calibrateCamera`
- `cv2.projectPoints`

其中：

- `ret` 常作为 RMS 重投影误差

经验上：

- `< 0.5` 像素通常可接受
- `< 0.2` 像素更理想

### RealSense 的特别提醒

RealSense 输出的彩色图往往已经做过一定校正，因此：

- 你自己标出来的内参
- 不一定和实际输出图像完全匹配

因此在真实应用中，更推荐：

- 直接使用 RealSense API 提供的 intrinsics

或者：

- 使用 Intel 官方标定工具重新标定

## 四、相机坐标系如何转机械臂基坐标系？

常见有两种手眼关系：

### 1. 眼在手外（Eye-to-Hand）

- 相机固定在机械臂工作区域外部
- 不随机械臂一起运动
- 相机观察整个工作区

### 2. 眼在手上（Eye-in-Hand）

- 相机安装在机械臂末端
- 随机械臂末端一起移动

本课程的 3D 抓取主要使用：

- `眼在手外`

---

## 4.1 手眼标定原理

手眼标定的目标是求出：

- 相机坐标系与机械臂坐标系之间的固定变换关系

### 眼在手上时

目标通常是求：

- `T_camera_to_gripper`

### 眼在手外时

目标通常是求：

- `T_camera_to_base`

### 为什么能求出来

因为在多次采样时：

- 机器人末端位姿可通过正运动学得到
- 标定板相对于相机的位姿可通过视觉算法得到

采集多组不同姿态之后，就可以构造多个矩阵约束方程。

这类问题通常最终会被整理成：

- `AX = XB`

再用经典算法求解：

- Tsai-Lenz
- Park-Martin
- Dual Quaternion

### 直观理解

可以把它理解成：

- 让“手”动几次
- 让“眼”也对应观察几次
- 比较每次变化量
- 反推出“眼”和“手”之间固定不变的关系

## 4.2 眼在手外 3D 视觉抓取实战

本节采用：

- 眼在手外
- Aruco 标定板
- 线性最小二乘拟合

对应脚本：

- `4.3d_calibrate_test.py`

### 设备要求

- 机械臂具备 `XYZ` 运动 API
- 如果是六轴机械臂，需保持末端欧拉角固定
- 深度相机固定安装
- 机械臂底座固定
- 吸盘夹具固定
- 相机视野要尽量覆盖全部预设标定点

### 标定板准备

建议：

- 使用 Aruco 标记
- 边长约 `50 mm`
- 安装平整
- 检测稳定

### 标定运行命令

```bash
python 4.3d_calibrate_test.py --visualize --calibrate
```

### 核心求解代码

```python
self.T_camera2base = base_coords @ np.linalg.pinv(cam_coords)
```

它本质上是：

- 用线性最小二乘方式拟合一个 `4x4` 齐次变换矩阵

### 标定时流程

1. 机械臂先运动到准备位置
2. 开启负压吸盘
3. 你有 10 秒安装 Aruco 标定板
4. 标定板需尽量安装规范：
   - 凹面对准吸嘴
   - 笔直朝前
   - 尽量水平
5. 机械臂会走到多个预设点位完成采样
6. 最终在 `save_parms` 中生成：
   - `camera2base.npy`

### 抓取测试运行命令

```bash
python 4.3d_calibrate_test.py --visualize --recognize
```

使用方式通常是：

```python
cam_pt = np.array([*ctr, 1.0])
base_pt = self.T_camera2base @ cam_pt
```

也就是直接将：

- 相机坐标系下的点

转换到：

- 机器人基坐标系

### 正常误差范围

由于存在：

- 标定误差
- D435 深度误差
- Episode1 J1 回隙

抓取位置相对目标几何中心有：

- `±10 mm`

的误差通常属于正常范围。

若误差明显大于这个范围，建议重点检查：

- 深度相机状态
- 相机视角覆盖
- 光照
- Aruco 板安装质量
- 机械臂底座和紧固件
- 桌面是否抖动

## 五、附录一：本课用到的矩阵性质

设矩阵 `A` 可逆，则存在唯一矩阵 `A^-1`，满足：

- `A * A^-1 = I`
- `A^-1 * A = I`

其中：

- `I` 是单位矩阵

可以通俗理解为：

- `A` 是一个操作
- `A^-1` 是撤销这个操作的反操作

前提是：

- `A` 必须是可逆方阵

---

## 六、附录二：矩阵顺序与逆矩阵理解

### 场景设定

假设：

- 坐标系 `A`
- 坐标系 `B` 相对 `A` 向右平移 3 个单位
- 点 `P` 在 `B` 中坐标是 `(1, 0)`

### 情况 1：从 B 到 A

已知点在 `B` 中的表示，想求它在 `A` 中的位置：

- 应使用 `T_A_B`

### 情况 2：从 A 回到 B

已知点在 `A` 中的表示，想反推它在 `B` 中的位置：

- 应使用 `T_A_B` 的逆矩阵

### 错误示例

若矩阵顺序写错，或者该取逆时没取逆，就会得到完全错误的结果。

因此在写坐标转换时，最重要的习惯是始终先问自己：

- 这个点现在是在哪个坐标系里表示的？
- 我要把它变换到哪个坐标系？

## 七、附录三：反投影矩阵形式推导

### 前向投影

相机内参矩阵 `K` 用来把相机坐标点投影到像素坐标。

### 反投影（de-projection）

当已知：

- 像素坐标 `(u, v)`
- 深度 `Z`

时，就可以反过来恢复相机坐标系下的三维点。

本质上就是：

- 对投影过程做逆变换

最终会得到常见分量形式：

```python
X = (u - cx) * Z / fx
Y = (v - cy) * Z / fy
Z = depth
```

这就是深度相机中最常用的三维恢复公式。

## 八、总结

本节内容的核心链路是：

1. 识别图像中的目标像素位置
2. 从深度图读取深度
3. 用相机内参反投影得到相机坐标系下的三维点
4. 用手眼标定得到相机到机器人基座的变换
5. 把相机坐标转换到机器人基坐标系
6. 再调用机械臂运动接口完成抓取

如果这条链路打通，那么 3D 视觉抓取就已经具备了最关键的基础能力。

# 六轴机械臂视觉抓取指导

本文档用于梳理六轴机械臂视觉引导抓取的核心知识，分为 `3D 视觉抓取` 与 `6D 视觉抓取` 两部分，帮助理解实现流程、关键问题与常见应用场景。

---

## 1. 课程目标

本课程的核心目标是利用六轴机械臂实现视觉引导抓取目标物体，主要包括两类任务：

- `3D 视觉抓取`
- `6D 视觉抓取`

两者的区别在于是否需要精确控制机械臂末端姿态。

---

## 2. 3D 视觉抓取与 6D 视觉抓取

### 2.1 3D 视觉抓取

3D 视觉抓取是指在视觉信息引导下，让机械臂末端只需要在空间中移动到合适的三维位置 `(x, y, z)` 来实现抓取，姿态通常保持不变或已固定。

换句话说，它主要关注：

- `在哪里抓`

而对抓取时末端绕各坐标轴的旋转姿态要求较低，或者姿态已经提前固定。

### 2.2 6D 视觉抓取

6D 视觉抓取是在 3D 位置信息基础上，进一步同时确定机械臂末端在空间中的旋转姿态，即不仅要知道：

- `在哪里抓`
- `以什么姿态抓`

它要求完整获取目标物体在空间中的：

- 位置 `(x, y, z)`
- 姿态 `(roll, pitch, yaw)` 或等价的旋转表示

并根据工艺需求对机械臂末端进行更灵活、更精确的控制。

### 2.3 对比总结

| 类型 | 关注重点 | 是否需要姿态控制 | 典型特点 |
|---|---|---:|---|
| 3D 视觉抓取 | 目标三维位置 | 否或弱要求 | 末端姿态固定 |
| 6D 视觉抓取 | 目标位置 + 目标姿态 | 是 | 末端姿态需精确匹配 |

---

## 3. 从结果倒推：实现视觉抓取需要掌握什么

实现视觉抓取，建议用“从结果倒推”的方式理解：

1. 先明确机械臂最后要完成什么动作。
2. 再反推视觉系统需要提供什么信息。
3. 再反推这些信息如何从相机中获得。
4. 最后梳理坐标变换、运动学、控制接口之间的关系。

# 一、3D 视觉抓取

## Q1. 如何实现 3D 视觉抓取？

要实现 3D 视觉抓取，首先需要确定目标物体的三维位置，然后把该位置转换到机械臂坐标系中，最后让机械臂末端移动到这个目标点即可。

3D 视觉抓取的核心是：

- 获取目标在空间中的三维位置
- 将相机坐标转换到机械臂坐标
- 控制机械臂末端到达目标点

关键知识点：

- 深度相机获取物体三维坐标
- 坐标转换与手眼标定
- 机械臂运动学求解

## Q2. 为什么要获取物体的三维坐标？

因为只有知道物体在空间中的 `位置` 信息，机械臂才能准确移动到对应位置进行抓取。

如果无法准确获取目标位置：

- 机械臂末端无法对准目标
- 抓取成功率会显著下降

关键知识点：

- 深度图像处理
- 目标检测或目标分割

## Q3. 如何从深度相机中提取物体的三维坐标？

通常包含以下步骤：

1. `相机内参标定`
   确定焦距、主点坐标、畸变参数等。

2. `图像处理与目标检测`
   在 RGB 图像或深度图中识别目标物体，找到目标区域或目标像素。

3. `深度值读取`
   在深度图或点云中提取对应像素的深度信息。

4. `像素坐标转相机坐标`
   通过相机内参，将像素坐标和深度值转换成相机坐标系下的三维坐标 `(X, Y, Z)`。

关键知识点：

- 相机内参原理
- 目标检测方法
- 像素坐标到相机坐标的转换

工程建议：

- 实际使用时，通常优先调用深度相机厂家提供的 API
- 厂家一般已经封装好了像素到三维坐标的转换过程

## Q4. 为什么要进行相机标定和手眼标定？

### 相机标定

相机标定的目的是确定相机的成像模型，包括：

- 焦距
- 主点坐标
- 畸变系数

这样才能保证从像素坐标到相机坐标的转换准确。

### 手眼标定

手眼标定的目的是确定：

- 相机坐标系
- 机械臂基坐标系或末端坐标系

之间的变换关系。

只有完成这一步，才能把相机测得的目标坐标映射到机器人世界坐标系，从而让机械臂准确运动到目标位置。

关键知识点：

- 标定板使用方法
- 棋盘格或圆点阵标定
- 手眼标定算法
- `AX = XB` 模型
- Tsai 等手眼标定方法

## Q5. 机械臂如何根据物体坐标移动到目标点？

机械臂通常需要经过以下步骤：

1. 根据手眼标定结果，将目标转换到机械臂基坐标系下。
2. 根据目标点求解逆运动学。
3. 得到对应关节角度。
4. 调用机械臂控制接口或运动 API 进行运动。

关键知识点：

- 机械臂正运动学
- 机械臂逆运动学
- 机械臂控制 API

## Q6. 3D 视觉抓取常见的应用场景有哪些？

常见应用包括：

- 箱子或料箱取料
- 生产线分拣
- 简单装配

特点是：

- 只需要知道物体的大致空间位置
- 对抓取姿态要求不高

## 3D 视觉抓取小结

实现 3D 视觉抓取的核心在于：

- 准确获取目标三维坐标
- 完成相机坐标到机械臂坐标的转换
- 通过运动学求解驱动机械臂到达目标点

因此通常需要掌握：

- 深度相机使用
- 相机标定
- 手眼标定
- 机械臂运动学

# 二、6D 视觉抓取

## Q1. 如何实现 6D 视觉抓取？

6D 视觉抓取不仅需要获取物体在空间中的位置 `(x, y, z)`，还需要获取物体的姿态信息。

因此实现流程通常是：

1. 获取目标的三维位置
2. 估计目标的空间姿态
3. 将目标位姿转换到机械臂基坐标系
4. 根据抓取工具安装方式与工艺要求，计算末端最终抓取位姿
5. 通过逆运动学控制机械臂运动到该位姿

关键知识点：

- 物体姿态估计
- 旋转矩阵
- 四元数
- 机械臂带姿态的逆运动学求解

## Q2. 为什么需要估计物体的姿态（朝向）？

因为有些物体不只是“抓到就行”，还必须按正确方向抓取。

典型原因包括：

- 物体有明显方向性，例如螺丝刀、插头、异形零件
- 装配工艺要求末端姿态与物体姿态匹配
- 后续动作如插配、旋拧、摆放，对姿态精度要求较高

关键知识点：

- 6D 位姿估计算法
- 姿态表达方式
- 任务工艺约束

## Q3. 如何从相机中估计物体的朝向信息？

常见方法有两类：

### 1. 基于特征的传统方法

在 RGB 图像或点云中提取物体特征点，再和模板或 CAD 模型进行匹配，进而求解物体姿态。

典型方法包括：

- PnP 位姿求解
- ICP 点云配准

### 2. 基于深度学习的方法

输入 RGB-D 图像或点云，由神经网络直接输出目标的 6D 位姿。

典型方向包括：

- 6D 位姿估计网络
- 抓取检测网络

本课程使用的是：

- `GraspNet`

关键知识点：

- PnP
- ICP
- 深度学习 6D 位姿估计
- 点云处理

## Q4. 如何将物体姿态映射到机械臂末端姿态？

完成手眼标定后，可以将物体在相机坐标系下的位姿转换到机器人基坐标系下。

此时需要做三件事：

1. 将物体旋转信息转换到机器人坐标系
2. 结合末端执行器安装角度进行补偿
3. 结合抓取工具结构、夹爪方向、工艺需求，计算最终抓取姿态

本质上是进行以下变换链拼接：

- `RobotBase <- Camera <- Object`

关键知识点：

- 齐次变换矩阵
- 旋转矩阵
- 欧拉角
- 四元数
- 末端安装补偿

## 6D 视觉抓取小结

6D 视觉抓取是在 3D 视觉抓取基础上的进一步扩展。

它不仅要求知道目标在哪里，还要求知道目标朝向如何，并让机械臂末端以合适姿态去接近和抓取目标。

因此除了 3D 抓取所需能力外，还需要掌握：

- 物体姿态估计
- 坐标变换链拼接
- 末端姿态补偿
- 带姿态约束的机械臂逆运动学

---

## 4. 3D 与 6D 视觉抓取的知识链路

可以把整套能力理解为如下知识链：

1. 相机采集图像与深度
2. 识别目标物体
3. 获取目标位置或位姿
4. 完成坐标变换
5. 计算机械臂目标位姿
6. 求解运动学
7. 控制机械臂执行抓取

其中：

- `3D 抓取` 停留在“位置”层面
- `6D 抓取` 进一步进入“位置 + 姿态”层面

---

## 5. 实践建议

在项目落地时，建议按以下顺序推进：

1. 先打通深度相机取点流程
2. 再完成相机标定和手眼标定
3. 先实现 3D 抓取闭环
4. 再增加姿态估计模块，实现 6D 抓取
5. 最后结合真实夹具、工艺动作做抓取姿态补偿

这样可以降低联调复杂度，也更容易定位问题。

## 1.0 先看几个核心问题

| 问题 | 答案 |
|---|---|
| 在描述多个关节连杆的空间关系时，为什么单纯使用齐次变换矩阵难以直接管理各关节的相对运动？ | 因为每个关节都有自己的坐标系，如果只写总变换矩阵，很难统一地表达“每一节到底怎么转、怎么平移”。DH 参数提供了一套标准化描述方法。 |
| 为什么要学习正运动学？ | 因为正运动学解决的是“给定关节角度，末端在哪里、朝向如何”。这是最基础的运动学问题。 |

## 1.1 机械臂的基本结构概念

---

## 1.1.1 关节（Joint）

在机器人或机械臂中，关节（Joint）是连接相邻连杆的机械机构，用来允许两个连杆之间产生相对运动。

按照运动类型，最常见的关节有两类：

- `旋转关节（Revolute Joint）`
- `移动关节（Prismatic Joint）`

---

## 1.1.1.1 旋转关节（Revolute Joint）

### 定义

旋转关节允许相邻连杆绕某一固定轴做角度变化，因此也常被称为：

- 铰链关节
- `R` 关节

### 运动特性

- 唯一自由度是角度
- 通常记为 `θ`
- 在二维里像一根杆绕铰链转动
- 在三维中旋转轴可能是水平、垂直或倾斜方向
- 一般会有限位，如 `-180° ~ +180°`

### 举例

- 六轴机械臂中的大多数关节
- 抓手开合结构中的转动关节
- 人形机器人中的绝大多数关节

Episode 1 六轴机械臂的六个关节本质上都是旋转关节。

### 优点与应用

- 适合需要灵活摆动和定位的任务
- 结构成熟
- 便于通过电机和减速机直接驱动

---

## 1.1.1.2 移动关节（Prismatic Joint）

### 定义

移动关节允许相邻连杆沿某个方向做直线滑动或伸缩，因此也称为：

- 滑动关节
- `P` 关节

### 运动特性

- 唯一自由度是位移
- 通常记为 `d`
- 常见实现方式包括气缸、丝杠、线性滑轨等
- 一般也会有限位，如 `0 ~ 100 mm`

### 举例

- 直线模组
- 伸缩机械臂
- 某些 CNC 或笛卡尔机器人结构

### 优点与应用

- 适合直接做平移或插拔动作
- 在某些场景下能扩大工作空间
- 适合做线性进给和线性定位

---

## 1.1.2 连杆（Link）

连杆（Link）是连接关节与关节之间的刚性构件，它负责把一个关节的运动和力传递到下一个关节或末端执行器。

你可以把它理解成：

- 机械臂的骨架

在多关节机器人中，结构通常是：

- 关节 -> 连杆 -> 关节 -> 连杆 -> 关节

### 连杆的特点

- 连杆本身不主动运动
- 它通过关节带动整体产生运动
- 连杆有固定长度和几何形状
- 在运动学建模中，通常主要关注其几何长度和相对位置关系

### 在运动学中的作用

为了分析机械臂运动，每个连杆通常会绑定一个坐标系，用来描述它与相邻连杆之间的变换关系。

这些关系正是：

- DH 参数
- 齐次变换矩阵

要解决的问题。

---

## 1.2 DH 参数的由来与目的

很多人刚接触机械臂时会问：

- 我只是想知道末端在哪里
- 只是想让末端到某个目标点
- 为什么还非得量一大堆参数？

### 本质目标

机械臂可以看成很多“关节-连杆”小段串起来的结构。

核心任务是：

- 描述每个关节相对于前一个关节的位姿

如果能把这些小段之间的相对关系都描述清楚，那么将这些小段对应的变换矩阵依次相乘，就能得到整台机械臂的：

- 正运动学模型

而逆运动学、轨迹规划、控制求解，也都会建立在这个模型上。

### 我们已有的武器：齐次变换矩阵

齐次变换矩阵很强，因为它一次性打包了：

- 旋转 `R`
- 平移 `t`

但现实中的问题是：

- 很难直接量出完整矩阵里的所有数字
- 每个关节都自己量一遍矩阵，不仅繁琐，而且不统一

### 思路转变：量几何量，而不是量矩阵

对于相邻两个关节，总能找到四个易测、可重复的几何量：

- `a`
- `alpha`
- `d`
- `theta`

这四个参数就足以生成相邻连杆间的齐次变换矩阵。

这就是：

- `Denavit-Hartenberg (DH) 参数法`

### DH 的核心价值

- 简洁：4 个量就能描述相邻变换
- 标准化：所有关节都用同一套路建模
- 通用：广泛用于教材、工业软件、科研论文
- 易复用：换一台机械臂，重新测参数即可

### 一句话总结

学习 DH 的目的，是用最少、最稳定的几何量，快速建立整条机械臂的位姿骨架。

---

## 1.3 定义 DH 参数（经典/标准法）

网络上关于 DH 参数的教程很多，但常见差异主要来自两类原因：

- 坐标系放置规则不同
- 经典 DH 与改进 DH 混用

因此你会看到不同资料中：

- 参数表长得不一样
- 编号方式不一样
- 坐标轴方向也不一样

这不是谁对谁错，而是规则不同。

本课程采用：

- 林沛群老师课程中的经典/标准 DH 定义方式

建议把重点放在：

- 坐标系是否放置清晰
- 四个参数的物理意义是否理解
- 整套规则是否前后一致

---

## 1.3.1 放置连杆坐标系

在经典 DH 中，放置坐标系的步骤大致如下：

### 步骤 1：定义 `Z_i`

让第 `i` 个坐标系的 `Z_i` 轴与第 `i` 个关节的运动轴重合：

- 若是旋转关节，对准旋转轴
- 若是移动关节，对准移动方向

这样做的目的是：

- 保证关节变量只影响 `Z` 轴上的运动定义

### 步骤 2：找到公共垂线

在相邻两个 `Z` 轴之间，找到最短连线，也就是：

- `公共垂线（common normal）`

它的方向定义为：

- `X_i`

如果两条 `Z` 轴相交，那么公共垂线长度为 0，此时 `X_i` 通过交点即可。

### 步骤 3：由右手定则得到 `Y_i`

根据右手定则：

- `Y_i = Z_i × X_i`

从而形成完整的右手坐标系。

### 一个重要理解

对于基坐标系：

- `X_0` 的方向往往可以自行约定

但从后续关节开始：

- `X_i` 的方向就受公共垂线约束

---

## 1.3.2 四个 DH 参数

经典 DH 一共使用四个参数：

| 参数 | 测量方向 | 几何含义 |
|---|---|---|
| `a_i` | 沿 `X_i` | 两条相邻 `Z` 轴之间的距离，也叫连杆长度 |
| `alpha_i` | 绕 `X_i` | 从 `Z_{i-1}` 到 `Z_i` 的扭转角 |
| `d_i` | 沿 `Z_{i-1}` 或按定义沿关节轴 | 相邻坐标系原点沿 `Z` 轴的偏移 |
| `theta_i` | 绕 `Z_{i-1}` 或按定义绕关节轴 | 相邻坐标系之间绕 `Z` 轴的旋转角 |

### 对不同关节类型的变量关系

对于旋转关节：

- `theta` 是变量
- `d` 是常量

对于移动关节：

- `d` 是变量
- `theta` 是常量

### 助记方式

可以记成两类：

- 沿轴平移：`a`、`d`
- 绕轴旋转：`alpha`、`theta`

### 关于 `X` 轴到底放在哪

在相邻关节建模时，常见有两种思路：

1. 让上一节坐标系的 `X` 轴沿公共垂线
2. 让下一节坐标系的 `X` 轴沿公共垂线

课程中通常选择第 2 种，因为对分叉链更自然、更通用。

### 关于 `Z` 轴方向正负

`Z` 轴正方向并不是唯一的，只要整套建模自洽即可。

例如同一台机械臂：

- `Z` 朝外
- `Z` 朝内

都可以建模成功，只是最终 DH 表会不同。

但要注意：

- 一旦改了 `Z` 轴方向
- 对应角度正方向和其他参数也必须一起调整

否则齐次变换矩阵就会出错。

课程中 Episode 1 的建模约定是：

- `Z` 朝外

## 二、正逆运动学

| 问题 | 正运动学 FK | 逆运动学 IK |
|---|---|---|
| 要解决什么？ | 关节角 -> 末端位姿 | 目标位姿 -> 关节角 |
| 典型场景 | 示教、仿真、状态反馈 | 抓取、路径规划、避障 |
| 为什么重要？ | 确定当前末端位置与姿态 | 让末端运动到目标点 |

本文主要讨论：

- 全旋转关节 `nR` 机械臂

例如：

- `6R` 工业机器人
- Episode 1 六轴机械臂

---

## 2.1 正运动学 —— “给角度，算末端”

正运动学（Forward Kinematics, FK）要回答的问题是：

- 已知每个关节角
- 末端执行器现在在什么位置、什么姿态

### 基本步骤

1. 建立 DH 表
2. 写出每一节的单节变换矩阵
3. 将所有单节矩阵依次连乘
4. 得到末端相对于基坐标系的总变换矩阵

### 单节变换矩阵的思想

在经典 DH 中，相邻两节之间的变换可拆成四步：

1. 绕 `Z` 轴旋转 `theta`
2. 沿 `Z` 轴平移 `d`
3. 沿 `X` 轴平移 `a`
4. 绕 `X` 轴旋转 `alpha`

这四步依次相乘，就得到单节变换矩阵。

### 总变换

如果机械臂有 `n` 节，那么末端总变换就是：

- `T_0_n = A_1 * A_2 * ... * A_n`

如果末端还有工具偏置 TCP，则继续乘上：

- `T_flange_tool`

### 从总变换矩阵中提取什么

从最终矩阵可以提取：

- 位置向量 `p`
- 姿态矩阵 `R`

它们共同组成末端位姿。

### 正运动学的作用

- 计算当前末端状态
- 仿真显示机械臂姿态
- 路径可视化
- 为雅可比矩阵和动力学分析打基础

### 工作空间

机器人工作空间是指：

- 在关节限位内，末端能够到达的所有空间点的集合

如果同时考虑姿态，则更准确地说是：

- 可达位姿空间

---

## 2.2 逆运动学 —— “给目标，算角度”

逆运动学（Inverse Kinematics, IK）要回答的问题是：

- 已知末端的目标位置和姿态
- 需要哪些关节角，才能让末端到达那里

这正是机械臂控制里最核心的问题之一。

因为在实际任务中，我们更常说的是：

- “让末端到这里”

而不是：

- “让 6 个关节分别转到这些角度”

---

## 2.2.1 常用 IK 求解方法

| 方法 | 适用特点 | 核心思路 |
|---|---|---|
| 几何 / 解析解 | 结构规则的机械臂，如 6R 球腕 | 通过几何关系和三角方程直接解出 |
| 代数解 | 更复杂的解析结构 | 通过符号消元得到闭式解 |
| 数值迭代 | 解析难、冗余机械臂 | 用误差函数和 Jacobian 迭代逼近 |
| 优化 / 约束解 | 要满足限位、避障等约束 | 以优化问题形式求解 |
| 学习 / 数据驱动 | 结构复杂、数据充分 | 用网络或回归模型近似 IK 映射 |

### 工程经验

通常遵循这个优先级：

1. 能用解析解就先用解析解
2. 没有解析解，再用数值法
3. 若有复杂约束，再用优化法

因为解析解通常：

- 最快
- 最稳定
- 最适合实时控制

---

## 2.2.2 通用解析解计算步骤（以 6R 机械臂为例）

对于典型 6R 工业机械臂，解析求解一般会经历以下步骤：

### 1. 准备

- 机械臂 DH 参数
- 目标位姿 `T`
- 机器人几何结构信息

### 2. 分离位置与姿态

如果是球腕结构，通常先计算：

- 腕中心位置

这样就可以把问题拆成两部分：

- 前 3 轴负责位置
- 后 3 轴负责姿态

### 3. 求前 3 轴

通过目标位置和腕中心几何关系，求解：

- `theta1`
- `theta2`
- `theta3`

### 4. 求后 3 轴

在已知前 3 轴的情况下，可求出后 3 轴需要达到的旋转关系，再进一步解析：

- `theta4`
- `theta5`
- `theta6`

### 5. 多解筛选

逆运动学往往不止一个解，因此还要进一步筛选：

- 是否超关节限位
- 是否接近奇异位形
- 是否发生碰撞
- 哪个解离当前姿态更近

最终再根据代价函数选择最优解。

## 2.2.3 常见逆运动学求解器 IK Solvers

实际工程中，我们大多数时候不会手写完整 IK 求解器，而是直接调库。

下面列出常见工具：

| 名称 | 解法类型 | 开源 | 平台 | 特点 |
|---|---|---:|---|---|
| IKFast | 解析解 | 是 | C++ / Python 绑定 | 超快，工业最常见 |
| MoveIt IK Plugins | 插件式 | 是 | ROS | 可接 IKFast、KDL、TRAC-IK |
| TRAC-IK | 数值 + 优化 | 是 | ROS / C++ | 比 KDL 更稳更快 |
| KDL | 数值迭代 | 是 | C++ / PyKDL | ROS 常用，稳定但偏慢 |
| Pinocchio | 数值优化 | 是 | C++ / Python | 快，适合控制与优化 |
| Robotics Toolbox for Python | 数值法 | 是 | Python | 教学和研究非常方便 |
| Modern Robotics Library | 解析 + 数值 | 是 | Python / MATLAB / C++ | 教材配套 |
| Drake | 数值优化 + 约束 | 是 | C++ / Python | 强约束、高级建模 |
| RoboDK | 解析封装 + 数值补充 | 否 | GUI + Python | 工业仿真和离线编程方便 |
| PyBullet IK Solver | 数值法 | 是 | Python | 仿真方便，精度一般 |
| CoppeliaSim IK | 数值法 | 基础版开源 | GUI + Lua / Python | 教学仿真友好 |

### 关于“支持冗余臂”

冗余机械臂指的是：

- 机器人自由度多于任务要求的自由度

例如：

- 末端位姿需要 6 个变量
- 机械臂却有 7 个关节

这时会有无穷多个解。

支持冗余臂的求解器可以：

- 找到一个可行解
- 甚至按“更优”准则挑选一个更合适的解

### 关于“支持约束”

真实机器人控制中，经常要额外考虑：

- 关节限位
- 奇异点规避
- 避障
- 姿态偏好
- 工具方向约束

支持约束的求解器能在解算时把这些限制一起考虑进去，更适合真实项目。

## 四、学习建议

建议按以下顺序学习这部分内容：

1. 先理解关节和连杆
2. 再理解 DH 参数的四个量分别代表什么
3. 学会根据 DH 参数写出单节变换矩阵
4. 学会通过连乘做正运动学
5. 再学习逆运动学求解思路
6. 最后结合求解器和仿真软件做实际验证

推荐练习方式：

1. 先在 RoboDK 中验证 FK 结果
2. 再在 API 中调用 MoveJ / Move XYZ
3. 再对比 IK 求出来的姿态是否和仿真一致

---

## 五、实践提醒

在实际调试中，逆运动学经常会出现：

- 某些姿态无解
- 前方容易解，背面难解
- 同一个目标有多组解
- 仿真能到，真机因为限位到不了

这些现象都是正常的。

因此工程上通常要做：

- 解筛选
- 姿态约束
- 关节限位检查
- 奇异性检查

不要把 IK 想成一个“永远一定能返回唯一正确答案”的黑盒。

---

## 六、总结

这部分内容的逻辑链是：

1. `DH 参数`：建立机械臂几何模型
2. `正运动学`：从关节角推末端位姿
3. `逆运动学`：从末端位姿反求关节角

它们共同构成了机械臂运动控制的基础骨架。

如果你已经掌握了：

- 坐标系
- 姿态
- 位姿
- DH 参数
- FK / IK

那么后面学习：

- 视觉抓取
- 手眼标定
- 路径规划
- 轨迹控制

就会顺很多。
